# Odin - Etch a Sketch
A browser-based drawing app Project created as part of The Odin Project curriculum.

## Project Description
- This application dynamically generates a grid of interactive squares, allowing users to create pixel art by hovering over the cells.

### Features
- A resizable grid (up to 100x100) initialized at 16x16.
- Real-time drawing via mouse hover, leaving a colorful trail.
- User prompts to customize grid size while maintaining total canvas dimensions.
